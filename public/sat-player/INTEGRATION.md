# SAT native interface

User-supplied SAT-Bluebook source integrated for Review. Production index.html receives only the current paper through a nonce-bound parent bridge. It does not load sample questions or access localStorage. preview.html is an independent reference gallery including the supplied mathematical and break screens, with sample-only storage. It never installs samples into personal content.

Loading: randomized 3000–6000 ms, restored after interruption. Submission: 20% simulated failure; retry preserves answers. Only a confirmed local save permits the success page. Alt+Esc: pause timer and show temporary absence; Enter: resume. More > Unscheduled Break: timer continues. Alt+R review; Alt+N next question; Alt+M mark. Extended review has Next available; confirmation locks the previous module. Actual test retains English-only scope.
