# 题目数据规范

所有样题集中在 `questions.js`，作为 `window.DET_CONTENT` 对象加载。工程不用服务器数据库。完整可参考 `assets/sample-question-bank.json`。

## 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| sections | 对象数组 | 分节名称、显示数量、计时、统计标签 |
| words | 字符串数组 | Read and Select 中逐个显示的词 |
| sentences | 对象数组 | before、prefix、word、after |
| cloze | 字符串数组 | 用 `前缀{缺少的字母}` 表示一个填字位置 |
| dictation | 字符串数组 | 听写样句，由浏览器英语语音读出 |
| reading | 对象 | title、paragraphs、sentences、options、passageChoices、highlights、ideas、titles |
| listening | 对象 | scenario、audio、blanks、turns |
| listeningQuestions | 字符串数组 | 与 listening.blanks 对应的三个问题标题 |
| photo | 相对路径 | 图片描述与口语共用的样图 |
| writingPrompt / followup | 字符串 | 互动写作第一问与追问 |
| speakingPrompt | 字符串 | 主题口语，可用换行列出提示 |
| conversation | 字符串数组 | 互动口语逐次读出的提示 |
| samplePrompt | 字符串 | 写作及口语样本提示 |

## 单句填字示例

```js
{before:'The team found a practical', prefix:'solu', word:'solution', after:'to the problem.'}
```

`word` 必须以前缀 `prefix` 开头。输入格数量等于完整词长度减去前缀长度，使用英文字母。不要在 prefix 中放 HTML。

## 段落填字示例

```js
'Residents work tog{ether} to trans{form} empty spaces.'
```

每一组花括号对应连续的缺失字母。现有解析器匹配英文单词，不支持一个位置内空格或标点。

## 互动阅读

`sentences` 使用 `[0]`、`[1]` 这样的编号占位符，与 `options[0]`、`options[1]` 对应。编号从 0 开始。补句页将第三段暂时替换成空位；要调整空位段落请修改 `readingText()`。高亮题的 `answer` 字段是维护参考，本演示不自动判分。

## 互动听力

`blanks` 的 text 是答句前半部分，answer 仅为维护参考。`turns` 中每一项包含对方 audio 及候选 choices。演示保留前面的对话内容，不自动判分或生成新题。

## 素材

相对路径必须位于工程目录，优先放在 assets/。修改照片或字体后运行 `node scripts/build.mjs` 重新内嵌到单文件版。请勿把账号、密码、真实身份证信息、摄像头录制等放进题库或资源库。

## 演示规模

样题数量用于展示控件与转场，部分数量比完整考试短。F2 的“缩短示例流程”进一步缩短首轮词汇、填字、听写与图片题。正式考试的自适应出题与评分不在本工程范围内。
