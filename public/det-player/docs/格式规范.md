# 格式规范

## 布局基准

基准视口 1536 × 864，居中卡片 1280 × 720，位置 x=128、y=72，圆角 8。卡片按 `min(窗口宽/1536, 窗口高/864)` 等比缩放，保持截图中的四周留白。页面适合桌面；窄窗口采用等比缩放，不声称与官方移动布局一致。

| 元素 | CSS 基准值 |
|---|---|
| 顶部栏 | 高 102；左右内边距 40；底边 2 |
| 底部栏 | 高 96；左右内边距 40；上边 2 |
| 计时数字 | 23 / 30，字重 750，等宽数字 |
| 计时说明 | 16，字重 500 |
| 主问题标题 | 28 / 32，字重 700 |

## 字体与颜色

使用本地 `DuolingoSansVF.woff2` 变体字体，支持 100–900 字重。字体加载失败时回退 Arial；因此不要把字体文件从多文件版移走。离线单文件已内嵌字体。

| Token | 值 | 用途 |
|---|---|---|
| --ink | #4b4b4b | 标题、正文、计时 |
| --blue | #51aff0 | 主按钮、进度、选择态 |
| --blue-dark | #4095ca | 按钮底部 |
| --blue-light | #e1f3ff | 选择、焦点 |
| --border | #e5e5e5 | 分隔线、边框、禁用背景 |
| --muted | #afafaf | 次要标签、占位、禁用文字 |
| 页面背景 | #f0f0f0 | 卡片外背景 |
| 输入背景 | #f7f7f7 | 听写、听力填空 |

## 状态

- `.selected`：蓝边、浅蓝背景，单选圆点填充。
- `.chosen`：词汇判断按下后的短暂选择态，随后换题。
- `.has-value`：阅读下拉选定状态，同时更新左侧空位。
- `:disabled`：灰色按钮，不保留蓝色底部阴影。
- `:focus-visible`：键盘焦点轮廓。填字输入格使用内部蓝色描边。
- 补句的 `.preview` 是悬停状态，`.selected` 是确认状态。
- 正常计时按时间截止点计算；切换阅读子题不重置公共计时。预览冻结模式不扣时间。

## 动效

| 动效 | 实现 |
|---|---|
| 按钮按下 | 60ms，向下 4px，阴影收起 |
| 页面进入 | 130ms 淡入 |
| 音频波形 | 550–800ms 循环，高度变化、错开相位 |
| 录音状态点 | 1.1s 透明度循环 |
| 角色身体 | 3.4s 轻微上下移动与旋转 |
| 角色眨眼 | 5.2s 周期 |
| 角色说话 | 500ms 身体动作，200ms 嘴部动作 |
| 扫描线 | 2.5s 上下扫描 |
| 上传状态 | 随机增长 4–20%，随机停顿 450–1699ms；进度过渡 90ms。最长约 16s，预览在 100% 停留 |

以上动画时长是本地演示参数。静态参考图不能确定原版时序；未取得原版动画源文件的部分已在差异记录中标明。系统开启减少动态效果时，会压缩非必要动画。

## 文案及修改原则

页面内保持英文考试文案。中文维护说明放在 F2 选择器、资源库与文档中。先改共享组件，再校验各题型；不要按截图绝对坐标单独摆每个控件。样题可以替换，题型布局由 app.js 决定。
