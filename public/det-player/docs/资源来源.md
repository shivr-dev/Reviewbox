## 字体

`assets/fonts/DuolingoSansVF.woff2`：官方页面 CSS 中公开引用的 Duolingo Sans 变体字体，76,404 字节。来源：

https://dy8n3onijof8f.cloudfront.net/static/fonts/duolingo-sans/DuolingoSansVF.woff2

在官方页面字体规则中同时观察到 duolingo-sans / din-round 的别名。字体版权归权利人所有。本地演示包含此字体便于复核，来源可追溯，不表示授予商业或再次分发许可。

## 图标与角色

`icons.js` 及 `assets/icons/*.svg` 是本工程代码绘制的 SVG。计时、关闭、勾、扬声器等依据参考外形重建。`conversation-partner.svg` 为对公开 Interactive Speaking 配图的近似角色重绘，含可动画的身体、眼睛和嘴部组；并非提取的官方原始动画素材。
