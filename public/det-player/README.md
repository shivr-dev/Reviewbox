# Duolingo English Test 界面演示

可交互 HTML/CSS/JavaScript 工程。包含分节页、词汇判断、单句填字、段落填字、听写、互动阅读、互动听力、图片写作、互动写作、图片口语、主题口语、互动口语、写作与口语样本，以及准备、退出、上传和完成状态。

## 打开

- 最方便：双击 `Duolingo-English-Test-离线单文件.html`。字体、示例照片和脚本已内嵌。
- 开发：安装已有的 Node.js 后运行 `node scripts/serve.mjs`，访问 `http://127.0.0.1:4176`。不需要 npm 安装依赖。
- 也可以直接打开 `index.html`；资源均使用相对路径。
- `library.html` 是页面入口和资源库，每个题型都能单独预览。

## 使用

默认从第一个分节页开始。按 **F2** 打开场景选择器；可以冻结计时、缩短示例流程或直接进入任意题型。网址中加 `?preview=1` 会冻结计时，便于检查外观。正常模式会在计时结束后推进。

填字支持逐字输入、自动跳格、左右键、Tab、退格和粘贴。阅读选词会同步到文章；补句支持悬停预览；拖选文章会填入答案框。听写显示剩余重播次数。互动听力保留已选择的对话。写作支持字数显示和追问页。口语显示录音波形、状态点和角色动效。

## 改题

编辑 `questions.js` 的 `window.DET_CONTENT`。不要改样式文件来存放题目。见 `docs/题目数据规范.md`；导出的完整示例 JSON 在 `assets/sample-question-bank.json`。修改后运行 `node scripts/build.mjs` 更新资源库、清单及离线单文件。

## 核对范围

这是一套本地界面复刻，依据用户提供的四张图、2026-10-05 实际打开的官方模考和官方题型资料。外框、字体、词汇判断按钮、听写和互动阅读/听力的关键尺寸已现场核对。

未观察到的正式设备验证、结束页、部分题型和动画细节采用演示实现；角色 SVG 为重绘，示例音频为浏览器语音合成。不能据此宣称全部页面和动画已达到像素级 100% 一致。具体证据与差异在 `docs/参考与差异.md`。

本工程不接入自适应出题、计分、监考或官方服务；摄像头、身份证、手机配对和录音均为界面模拟。答案仅存储在当前浏览器的本地存储中，不包含官方账户信息。语音合成是否可用取决于浏览器及系统的英语语音。

## 工程目录

| 文件 | 用途 |
|---|---|
| index.html / app.js | 页面入口、路由、互动状态 |
| styles.css | 布局、字体、组件状态与动画 |
| questions.js | 可替换的示例题目 |
| icons.js | 矢量图标和角色 |
| assets/ | 字体、图标、照片、示例题库、资源清单 |
| library.html | 页面与资源预览 |
| docs/ | 格式规范、数据规范、来源、差异、验证记录 |
| scripts/build.mjs | 重建离线单文件与资源库 |
| scripts/serve.mjs | 仅绑定 127.0.0.1 的本地服务 |
