# ACT 国际机考界面 · 本地还原演示

打开 `ACT-单文件.html` 或双击 `启动ACT.cmd` 即可使用，无需安装、账号或联网。源码入口是 `index.html`。源码版可直接打开，也可使用 Node.js 运行 `node scripts/serve.mjs`，浏览器访问 http://127.0.0.1:4175/ 。

## 先看准备考试流程

提示页 → 考生声明 → Accept → 工具帮助 → Information → Instructions → 第一题。

- Decline 会显示确认，确认后进入退出页。
- Information 及之前的页面不开始计时。进入 Instructions 时才开始该科目计时。
- 作答时可以打开 Help Screen，再次点击返回原页；倒计时继续。
- 题目索引支持已答状态、旗标、未答和旗标筛选。
- F2 打开本地场景面板，可直接查看所有流程、选择科目、触发五分钟提醒与时间到。
- F2 → 重新开始本地演示，清除本演示的作答与工具记录。

## 本次实现的范围

当前国际 ACT 官方练习网站的 PSI 外框、Calibri 字体体系、顶部工具栏、双栏阅读、底部导航、计时、单选、旗标、索引、对比度、Line Reader、Magnifier、高亮、答案排除/遮盖；考前流程、结束确认、科目切换、休息、写作文本框与结束页。包含 5 类题目样例；题号循环使用小样例库，不含正式题库、评分或自适应。

这是界面与流程演示，不是官方考试客户端。不会连接 ACT/PSI，也不会上传作答。Connected 是本地界面状态文字。作答保存在当前浏览器的本地存储；文件模式下浏览器若限制存储，刷新可能丢失状态。

## 还原依据与边界

详见 `docs/准备流程核对.md` 和 `docs/参考与差异.md`。当前公开练习网站与较早的国际考场教程并非同一界面版本。本项目以当前练习网站为视觉依据，以官方国际教程为考前步骤依据；二者组合出的正式流程**不能宣称 100% 已核实**。

考前提示、声明、休息和结束页为依据公开步骤重建的示意，完整现行截图及逐字文案尚未获得。动效包含实际可用的浮窗拖动/缩放、菜单、索引、计时和保存等待；原版的准确过渡时长未公开，当前数值为近似。自动保存等待为本地模拟，不代表官方真实网络状态。

## 编辑与资源

- `questions.js`：题目样例、科目题数和时间。
- `app.js`：页面状态、交互与 SVG 图标。
- `styles.css`：字体、颜色、尺寸和响应式规则。
- `library.html`：可点击的场景入口和资源库。
- `assets/icons/`：导出的 SVG 图标；`assets/act-logo.png` 是当前公开页面已显示的品牌资源。
- `docs/格式规范.md`：布局、字体、动效参数。
- `docs/题目数据规范.md`：后续接题目的字段说明。
- 修改后执行 `node scripts/build.mjs` 更新单文件版和资源库。

最接近参考页面的环境是 Windows + Calibri + Chromium/Edge、浏览器缩放 100%。没有复制或打包 Windows 商业字体；其他系统使用 Arial 等回退字体，外观会有差异。
