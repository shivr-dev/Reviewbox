# 格式规范

## 字体

字体栈：`Calibri, Arial, "Microsoft YaHei", STXihei, sans-serif`。

| 元素 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 题干与文章 | 16px / 24px | 400 |
| 顶部 Answered / Total time left / 时间 | 16px / 24px | 400 |
| Item 标题 | 16px / 20px | 400 |
| End Test、Flag、Prev、Next | 14px / 21px | 600 |
| 文章标题 | 18px / 22.5px | 600 |
| 页面主标题 | 24px / 30px | 500 |
| 侧栏图标下文字 | 10px / 15px | 600 |

## 布局

- 顶栏 56px，左右外边距 10px。
- 工作区上、下边距 10px，左边距 10px；主卡片到侧栏间距 10px。
- 侧栏宽 115px；较窄屏幕缩至 80px/58px。
- 卡片题号栏高 54px；底部导航高 54px。
- 文章与问题各占剩余宽度 50%；两边分别滚动。
- 文章左右 padding 20px，题干区 padding 16px。
- 单选圆圈 13px；答案行至少 44px，行间距 5px。
- Line Reader 默认 625×400px，左 3px、顶 59px；标题栏 38px，阅读孔 40px。浮窗和孔分别可缩放。
- Index 宽 280px，窄屏浮于题目之上。

## 动效

菜单淡入 100ms；索引淡入并水平位移 10px/150ms；提示透明度 120ms；保存转圈 850ms/圈，等待 1100ms。以上为本地近似值。阅读器拖动、尺寸调整直接跟随指针，不增加弹性或延迟。系统减少动效偏好会关闭非必要过渡。

## 快捷键

F2：本地场景面板（非原版 UI）；Esc：关闭可取消弹窗或侧栏；Ctrl+Alt+I：索引；Ctrl+Alt+H：帮助；阅读器标题获得焦点后方向键移动；阅读孔获得焦点后上下键调整高度。
