# 后续替换题目

编辑 `questions.js`，无需改动布局组件。

`ACT_CONTENT.sections` 配置顺序、题数、时间：

```js
{ id: 'english', name: 'English', count: 50, minutes: 35 }
```

`ACT_CONTENT.banks[科目 id]` 是题目数组：

```js
{
  title: 'Passage title',
  passage: '<h2>Passage title</h2><p>Paragraph with <u data-target>underlined text</u>.</p>',
  prompt: 'Question text?',
  choices: ['First answer', 'Second answer', 'Third answer', 'Fourth answer']
}
```

- `passage` 可省略，省略时使用数学类单栏题目布局。
- `passage` 是受信任的本地 HTML；仅放经过编辑的内容，不直接导入未知网页或用户输入。
- `prompt` 和 `choices` 都作为纯文本显示。
- `data-target` 会在该题文章中显示黄色下划线目标片段。
- `figure: 'rectangle'` 是内置可编辑 SVG 图形示例；更多图形可扩展 app.js 的图形分支。
- `writing` 类型使用 `passage` 和 `prompt`，不使用 choices，显示作文输入框。
- 数组不足 count 时，演示版会循环使用样题。正式接入题目时请让数组与 count 一致，或修改 `question()` 读取规则。
- 本版单选字母为 A–D，4 个答案；没有评分字段和正确性反馈。若题型要求 5 个答案或不同标签，请同时扩展字母渲染。

浏览器保存键：`act-interface-v1`。答案键：`section-id:item-index`，题目索引从 0 开始，答案是选项的 0 起始编号。旗标、高亮、排除和遮盖也按此键隔离。改题库后使用 F2 清除旧演示数据，避免把旧答案映射到新题目。

执行 `node scripts/build.mjs` 后，单文件 HTML 与资源库会同步更新。
