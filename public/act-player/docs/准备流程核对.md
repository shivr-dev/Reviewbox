# 准备考试流程核对

核对日期：2026-10-05。对象：国际 ACT 机考；不是美国 ACT Gateway 或州考 TestNav。

| 步骤 | 公开依据 | 本地实现 | 核实程度 |
| --- | --- | --- | --- |
| 考前提示页 | 国际 CBT 官方教程第 1 页明确提及多张 notice pages | Before You Begin 提示页与 Next | 步骤已确认；具体页数、现行原文和外观未确认 |
| 考生声明 | 同一教程明确 Examinee Statement 和 Accept/Decline | 独立声明页，接受继续、拒绝退出确认 | 控件与分支已确认；当前逐字声明和版式未确认 |
| 工具帮助 | 当前国际官方练习链接实际进入 Help Screen | 独立帮助页，侧栏可再次打开并返回 | 当前公开练习版已观察；正式场次中的出现位置待核实 |
| 开考前 Information | 当前练习版实际显示 Directions，说明下一屏为 Instructions | 准备页，计时尚未开始 | 公开练习版已观察，文字使用本地概述 |
| 科目 Instructions | 当前练习版提供；官方教程说明 final information page 开始计时 | 打开该页时启动计时，Next 进入题目 | 步骤及开始计时规则已确认 |
| 第一道题 | 当前 PSI 界面实际观察 | Item 1、文章/问题双栏、单选、旗标、Prev/Next | 外框已观察；题目为原创样例 |
| 返回帮助/说明 | 当前界面 Help Screen、Index | 帮助原页返回，索引可返回说明；不会重置时间 | 交互已实现 |
| 监考员授权、身份核验、座位/考试口令 | 现有公开资料不足以确定现行屏幕 | 未伪造登录或口令页 | 待正式现行参考 |

本地顺序是“提示 → 声明 → 帮助 → Information → Instructions → 题目”。这是官方教程中的考前步骤与当前公开练习页面的组合，不等于已获取完整现行国际正式场次录像。
