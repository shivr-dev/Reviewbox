# MAP 界面格式规范

版本：1.0 · 2026-10-01

## 1. 画布与布局

基准逻辑宽度为 1556 px，参考高度 906 px。桌面画面整体按窗口宽度 / 1556 等比缩放，逻辑高度随窗口实时计算。用相同宽高比、浏览器 100% 缩放对照参考图。窄面板仍保留原图布局，建议全屏查看。

| 部件 | 基准尺寸 / 规则 |
| --- | --- |
| 居中内容 | 970 px，距基准画布左侧 293 px |
| 工具栏 | 高 50 px，白底，下方 2 px 蓝色边线 |
| 工具按钮 | 49 × 42 px；图形资源 49 × 40 px |
| 缩放值 | 48 × 40 px，灰色背景 |
| 工具栏与题面 | 间隔 8 px |
| 题面 | 高度 = 逻辑画布高度 − 135 px |
| 蓝色指令条 | 42 px，文字 16 px / 22 px |
| 双栏 | 左侧 58.5%，右侧 41.5%，中间 1 px 蓝线 |
| 固定底栏 | 58 px，底部 3 px 蓝线，内容宽 970 px |
| 下一题 | 116 × 40 px，圆角 4 px |
| 单选行 | 最小 42 px，圆形控件 20 × 20 px |
| 重置弹窗 | 524 px 宽，顶部位置 168 px，标题栏 61 px |

| 加载卡片 | 150 × 150 px，圆角 9 px |

不要使用新的大标题、圆角卡片导航或额外状态条覆盖答题区域。演示导航放在 F2 浮层，保持参考界面干净。

## 4. 状态与交互

- 单选：整行可点；选中行变灰，蓝色圆点出现。
- 多选：使用方形控件，最多选择 `maxSelections` 项；到达数量后，取消一个再换选。
- 双部分：每部分独立单选，两个部分都有选项后下一题启用。
- 排除：激活工具后每行左侧出现 ×；点击后文字变浅，无法选中；再次点击恢复。排除一个已选项会取消其答案。
- 拖拽：指针位移超过 5 个逻辑像素后显示词语浮层；目标空格高亮；落下后词语从词库隐藏。错误位置释放则原位保留。支持触摸和点击两步放入。
- 标记：激活高亮，拖选正文；用 `mark` 保留文字可选性。擦除工具点击高亮即可移除。
- 缩放：100%–200%，步长 25%；仅缩放题面，工具栏与底栏保持原尺寸。
- 重置：必须经过画面内确认弹窗，清除当前题面状态；取消保留答案。
- 记事本：当前题目内编辑，支持拖动和清空。阅读尺上下两段为 75% 黑色，各高 34 px，中间透明区高 18 px，纵向拖动，焦点态左右深蓝双线。再次点击工具栏图标或 Esc 收起。
- 下一题：仅依据填写完成状态启用，不进行正误判断。

| 动效 | 时长 | 曲线 / 说明 |

| 旋转加载 | 1000 ms 循环 | 30 条辐射线，逐条透明度 1 → .12 |
| 登录后加载 | 1600 + 300 ms | 演示等待与淡出，可在 app.js 修改 |
| 下一题加载 | 650 ms | 演示等待，不依赖网络 |
| 弹窗 | 160 ms | ease-out，透明度和 4 px 位移 |
| 选项反馈 | 130 ms | 背景色过渡 |
| 工具反馈 | 160 ms | 背景色 / 透明度 |

用户开启减少动态效果时使用 `prefers-reduced-motion` 降低动画。

## 6. 题目数据接口

入口为 `window.MAP_QUESTIONS` 数组。每题必须有 `id`、`type`、`number`、`subject`、`grade`。`id` 同时是页面 hash 路由，必须唯一。

| type | 必需的内容字段 | 对应参考 |
| --- | --- | --- |
| word-table | instruction, title, passage, prompt, word, choices | 阅读题 1 |
| split-parts | instruction, passage, preamble, parts | 阅读题 2 |
| single-choice | instruction, title, paragraphs, prompt, choices | 阅读题 3 |
| split-multiple | instruction, passage, preamble, prompt, choices, maxSelections | 阅读题 5 |
| pronoun | prompt, passage, secondaryPrompt | 语言题 1 |
| gap-match | preamble, prompt, passage, choices, gapCount | 语言题 6 |

单选示例：

```js
{
  id: 'reading-example', type: 'single-choice', number: 6,
  subject: 'Reading', grade: 8,
  instruction: 'Read the passage.', title: 'A New Passage',
  paragraphs: ['Your first paragraph.', 'Your second paragraph.'],
  attribution: '(Sample passage)',
  prompt: 'Which detail best supports the idea?',
  choices: ['First option', 'Second option', 'Third option', 'Fourth option']
}
```

`gap-match.passage` 中用 `{{0}}`、`{{1}}`、`{{2}}` 标识空格，与 `gapCount` 一致。`pronoun.passage` 中用 `{{we}}` 这样的标记生成可选代词。同一词语默认不能在多个空格重复使用。

双部分 `parts` 数组元素格式：`{label:'Part A', prompt:'...', choices:['...']}`。双栏长文使用受信任 HTML；图片请放入 `dist/assets` 后使用相对路径。

`question.schema.json` 提供公共字段和各题型字段的 JSON Schema。数据层不需要提供正确答案，本版本没有评分逻辑。

## 7. 可替换边界

- 添加题目：修改 questions.js；若希望 F2 面板列出，更新 app.js 中 screens 数组。
- 新增题型：增加 render() 分支、complete() 完成条件和对应样式。
- 更换颜色：优先修改 CSS 根变量和 design-tokens.json。
- 更换资源：保持路径与文件名，或同步修改 styles.css / index.html。
- 替换全部题目仍可保留工具栏、底栏、弹窗与加载动画。
- 页面使用原生浏览器能力，不需要 React、构建工具或测试服务器。

## 9. 考试前后状态

| 路由 | 画面 | 交互 |
| --- | --- | --- |
| #waiting | 黄色便签，等待监考确认 | F2 切到 confirmed 模拟监考通过；不自动放行 |
| #confirmed | 便签改为确认完毕，青色箭头出现 | 点击箭头后加载并开始答题 |
| #slow-down | 树懒举 SLOW 牌、监考 PIN 区 | 四位示例数字使 RESUME 启用，恢复演示 |
| #finished | 练习结束 | Take Another Test / Done |
| #test-ended | 正式结束布局，无成绩示例 | 打印 / 返回登录 |

等待确认纸张宽 698 px；便签宽 430 px，使用原图；中部内容宽 530 px；确认后按钮 140 × 44 px。作答过快卡片按原 CSS 的内容区 780 × 701 px、20 px 内边距与 1 px 边框构建；树懒 333 × 431 px。标题、提示文案沿用原页面模板，仅学生名、题目名与时间为演示数据。
