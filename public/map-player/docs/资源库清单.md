## 来源

- 纸张、品牌、图标字体：[参考练习页面](https://practice.mapnwea.org/)，页面引用的 `/images/` 和 `/fonts/` 公开静态资源。
- 工具栏 SVG：[Item presenter 资源](https://item-presenter-lib.mapnwea.org/presenter-api.js)，资源版本 `6bf74da`，由对应 CSS 中的 SVG data URL 解码存储。
- Open Sans：[Google Fonts](https://fonts.google.com/specimen/Open+Sans)。字体许可证随源字体适用条款保留；本项目没有重新声明字体所有权。
- `reference/01…09.png`、花卉参考、加载角色参考：用户提供的截图。原图完整保留，显示区域由 CSS 选取。

原始品牌、插画、照片、图标及题目摘录的权利归各自权利人。提供来源是为了明确素材出处，不代表本项目获得了第三方商标或内容的额外授权。

## 替换规则

SVG 尽量保留原 viewBox；透明图标无需重新绘制背景。纸张使用三段式拼接，避免将整张登录页作为不可交互背景。参考照片目前来自用户截图，若要更高清的照片，可用独立原图替换 `.flower-photo` / `.flower-field` 的背景资源及定位。
