# MAP 界面复刻

这是根据提供的 9 张截图制作的离线交互原型。HTML、CSS、原生 JavaScript，无需安装依赖、没有题库后端。

## 打开

1. 双击 `开始使用.html` 查看各个页面入口。
2. 或直接打开 `dist/index.html`。登录页随意填入两段示例文字后依次进入选择测试、学生确认和等待确认页；右上角 × 可直接跳到样例题。
3. 在答题页点击底部 **Question #**，或按 **F2** 打开所有演示状态。
4. 建议使用桌面版 Edge / Chrome 并按 **F11** 全屏，浏览器缩放保持 100%。页面按截图比例适配窗口。

本地双击可运行；若浏览器限制 file URL，使用任意静态服务器指向 `dist`。源码不依赖远程脚本、字体或图片。

## 文件结构

```
开始使用.html              演示入口
README.md                 使用说明
格式规范.md                布局、字体、动效及题目接口规范
资源库清单.md               图标和图片来源、对应关系
验收记录.md                实测交互及已知边界
dist/
  index.html              主页面结构
  styles.css              颜色、尺寸、布局及动画
  app.js                  界面交互和状态管理
  questions.js            六种可替换的示例题目
  question.schema.json    题目数据格式
  design-tokens.json      可复用设计参数
  library.html            可浏览的格式规范与资源库
  assets/                 本地字体、SVG、纸张背景和参考图片
  reference/              用户提供的九张原始截图
scripts/
  make-standalone.mjs     生成单文件离线 HTML
```

## 已实现

- 登录页、选择练习测试、学生信息确认 Yes / No、等待监考确认、确认完毕、作答过快暂停、练习结束、无成绩展示的正式考试结束页、九宫格缩放加载、半透明遮罩旋转加载。
- 词语拖拽表格、诗歌双栏双部分单选、整页单选、长文章多选、代词选取加填空、段落三空拖拽。
- 放大 / 缩小 / 回到 100%，高亮 / 擦除，拖动阅读尺，拖动和编辑记事本，选项排除。
- 选项反馈、答完后下一题亮起、下一题加载、重置确认、取消及键盘操作。
- 字词也可以“先点词语、再点空格”放入；点击已填空格可放回词库。

快捷键：H 高亮，E 擦除，L 阅读尺，N 记事本，A 排除选项，F2 演示面板，Esc 关闭当前浮层。输入文字时不会触发字母快捷键。

等待确认不会连接真实监考系统，也不会自动放行：按 F2 选择“已确认 · 开始考试”即可演示后续状态。作答过快页输入任意四位数字示例 PIN 后可恢复。最后一题完成后进入练习结束页。正式考试结束页仅展示外观和示例时间，不生成真实分数。

## 后续接题目

修改 `dist/questions.js` 即可替换内容。不要把题目写进工具栏或底栏。先按 `dist/question.schema.json` 保持字段和题型一致；详细示例见格式规范。`app.js` 的 `render()` 负责各题型布局，`complete()` 只决定下一题是否可用，不判断答案正误。

答题、记事本和表单内容仅保存在当前页面内存；刷新或换题会清除。演示登录不联网、不存储、不验证账户。内容字段支持受信任的静态 HTML；若以后接入外部题库，必须在导入环节对 HTML 做清洗。

## 还原边界

主要画面按用户截图制作，题面 Open Sans、纸张素材、工具栏 SVG 和单选/多选状态 SVG 来自参考页面的公开静态资源。九宫格 1.3 秒节奏和阅读尺的 34/18/34 px 结构按原页面 CSS 复现。新增确认与暂停页面参考原页面模板、样式和原插画。转圈、弹窗过渡、拖拽反馈及截图中小角色的上下浮动为重建效果，不能从单帧截图确认其原始节奏。记事本展开状态未提供截图，采用与现有风格一致的可操作实现。截图 9 未展示的文章尾部使用了示例文字。

## 本次交付补充

直接打开 `MAP-单文件.html` 可独立离线运行；`开始使用.html` 汇总全部 18 个画面入口。单文件中的资源库链接需和源码目录一起保留。源码修改后运行 `node scripts/make-standalone.mjs` 重新生成单文件。

选择页按原版模板提供 Grade / Course / Test Language，下拉项逐级启用；No 返回保留选择，Yes 进入等待确认。阅读和语言科目连接对应示例题。西班牙语选项目前演示选择及自我确认文案，题目仍使用现有英文示例；朗读控件保留禁用外观，未接音频。年级、学校和出生年是演示信息。
