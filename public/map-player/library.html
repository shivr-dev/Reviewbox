06 / 题目数据格式

编辑 questions.js 即可替换题目，保留 app.js 中的界面交互。六种题型共用工具栏、底栏和弹窗。

{
  id: 'reading-example', type: 'single-choice', number: 6,
  subject: 'Reading', grade: 8,
  instruction: 'Read the passage.', title: 'A New Passage',
  paragraphs: ['Your passage here.'],
  prompt: 'Choose an answer.',
  choices: ['First', 'Second', 'Third', 'Fourth']
}

可用类型：word-table、split-parts、single-choice、split-multiple、pronoun、gap-match。拖拽空格写作 {{0}}、{{1}}；代词候选写作 {{we}}。以下为原始界面包的展示格式。Review 中的评分、自适应选题与保存由学习系统处理；实际导入格式请使用「我的 → 复制出题 Skill」，本页示例不自动加入个人题库。
