## 同一系统的四页

- 学习首页直接复用当前 `HomeView`，读取真实计划，维持一个最强 CTA。
- 铁匠铺：奶油石与蓝顶小屋，暖木工具台；真实 React 词条、锁定、材料费用和持久化重铸结果比较。
- 附魔师：同样的建筑尺度与镜头、淡紫窗帘及少量星光；永久书籍图鉴、等级升级和免费装卸。
- 装备库：相同导航、字阶与按钮，原创装备陈列，稀有度同时使用文字和颜色。

场景、装备素材、React 操作、CSS 特效分层。SVG 只保留为小图标，不再使用 `ForgeScene` 整体几何场景。

## Alpha 入口与安全边界

「我的 → Alpha」主动加入，默认关闭。加入状态保存于当前学习账户的 settings，沿用原有离线存储与同步队列。加入后使用五个纯图标主入口和底部企鹅个人入口；未加入的用户仍使用正式界面。课程、考试和题库继续复用原有组件，未加入时访问工坊会显示加入说明。

可从设置退出，正式界面及既有数据继续保留。装备、矿石、装配、重铸和搭配使用账户内不可变操作记录与同步队列持久化，重铸候选可在刷新后恢复。材料购买使用已有点数账本。装备操作不写入掌握度、作答事件、考试成绩或 GPA；掉落资格来自已有学习记录。高级远征、Boss、委托等不属于本轮已实现范围。

Alpha 连对庆祝采用浅蓝白底、420ms 渐入、320ms 渐出，企鹅动画资源提前加载。3、5 和后续每 5 次为全屏里程碑；其他连对显示紧凑进度。支持 Escape、继续学习、焦点返回及减少动态效果偏好。素材加载失败仍保留原企鹅图与文字。
