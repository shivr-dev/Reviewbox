# 制作台与分组审核

实际入口位于「学科与资料 → 资料与导入 → 制作与排版」。仍使用原Reviewbox侧栏、主题、账户和数据库，没有新的模拟应用。

## 学习包制作台

- 新建空白学习包、打开JSON/ZIP、编辑已安装包、继续草稿。
- 编辑题干、材料、选项与答案、稳定ID连线、解析与分步解析、等价答案、知识点、技能、评分规则。
- MathLive插入公式、真实题目预览、Ketcher/Bioicons、函数和顶点坐标编辑、原图上传与阶段选择。
- 自动保存草稿；分块写入数据库和同步队列。草稿不是正式题目，不产生学习证据、掌握度、GPA或奖励。
- 修订检查通过现有PackUpdateReview：差异、冲突处理、归档和版本历史继续由现有安装流程管理。编辑不重新分配题目ID；原有keyterms/rubrics从安装快照恢复。
- 乐观revision检查避免旧窗口覆盖新草稿；账户切换不向新账户写旧草稿。同步不完整会提示，支持刷新列表。

## A4试卷排版

- 选择现有题目、拖动或按钮排序、每题图宽、答题留白、另起一页、页眉和页码。
- CSS原生多列分页使用A4尺寸和实际公式/题图；长题可以跨列分页，缩放不改变逻辑页号。
- 题图准备调用同一QuestionVisual渲染链，再复用捕获的SVG/PNG用于预览与DOCX。无AI重画或猜测题图。
- 修复JSXGraph空foreignObject占位层导致Word导出失败的问题；有实质嵌入内容仍拒绝，不能静默丢字。
- DOCX使用所选顺序、分页起点、图宽、留白、页眉与页码；浏览器和Word字体/排版引擎仍可能有少量换页差异，不宣称像素级一致。
- 生成与下载区分：只在用户明确点击下载时启动保存，不在生成后自动触发隐藏下载。Blob地址不在一秒后失效；重新生成保留旧地址，账户切换或页面退出时释放，并限制临时文档内存。

## 分组审核

- 错误：知识归属、评分、结构、题干条件冲突、素材缺失或引擎失败；显示具体题目及原因。
- 待人工确认：原图与重绘选择，支持按组保留原图/采用重绘。
- 引擎未检查：RDKit实际解析、Bioicons哈希与SVG检查、Mol*读取公开PDB CIF坐标。支持取消和失败重试。
- 仅视觉复核：对照题意检查标签、位置、单位与阶段后可确认本组或全部可确认题。
- 批量确认不写verified=true，不改变学习状态；引擎检查绑定图形签名，图形变化后旧结果失效。错误与未完成检查不能批量跳过。

## 验证

本地定向用例：草稿身份保持、核验状态失效、分块回读、并发revision拒绝、账户隔离、分页顺序、DOCX页眉/分页/编号、审核分组及安全批量确认、持续下载链接。代码类型检查与生产构建通过。浏览器实际打开原应用的两个制作台。

本地预览、演示题包、测试分子和个人数据库不在发布清单中。正式启动不新增任何示例内容。
