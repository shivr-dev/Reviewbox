# 家园企鹅动作

沿用 `public/learning-penguin.png` 原角色作为图像参考，由内置 imagegen 制作家园专用透明八帧图集。

| 图集                              | 排列        | 动作                                                 |
| --------------------------------- | ----------- | ---------------------------------------------------- |
| `learning-penguin-home-read.png`  | 4 列 × 2 行 | 坐下阅读、扫视、抬起书页、翻页、眨眼、抬头、继续阅读 |
| `learning-penguin-home-water.png` | 4 列 × 2 行 | 提壶、伸展手臂、倾壶、流水、收回、满意地眨眼         |

生成提示的核心约束：保持原企鹅的圆头、白环眼睛、椭圆嘴、白肚皮及暖纸微纹理；透明背景、无文字、等分四列两行、固定身体尺寸和脚部基线；动作必须包含手臂、道具、眼神变化。浇水图集做过一次边距修订；仍有极少水滴越过第五格左邻格边界，组件给浇水格左侧设置 8% 透明裁剪区，抑制串帧，完整企鹅与水壶保持可见。

`lib/home-companion-motion.ts` 保存逐帧停留时间及完整动作后的间歇。组件时钟只在姿势、活动身份或皮肤变化时重新建立；普通重渲染不重播，隐藏页面不会追赶跳帧。活动更换或卸载时解除 RAF、图像事件及偏好监听。

专用图集用于默认皮肤。其他服装继续显示现有真实服装图集，不会退回无服装企鹅；这些服装暂未制作单独翻页/倾壶图集，使用既有思考动作并保留活动道具。喝茶、画画、拉灯绳另有局部道具动作。减少动态效果偏好展示稳定首帧并停用道具动画。

资产为项目文件，源生成结果保留在 Codex generated_images；未使用 Cloudflare 出题调用，未使用 Python 修改图像。
