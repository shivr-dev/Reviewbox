## 已发现的入口问题

旧 Alpha 把铁匠、附魔、装备各占一级入口，学习计划、成绩和课程缺少直达入口；侧栏标签、材料与底部文字缺乏完整布局。旧导航使用 replaceState，无法正确逐步后退；资料导入初始学科固定语文，容易丢失学科上下文。均在本次整合范围内。
