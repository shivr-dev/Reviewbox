# Reviewbox 2.0 界面迁移与验收

## 基准

正式项目共用一套 React 工作台，入口由 `lib/workspace-route.ts` 和 `app/workspace.tsx` 分发。服务器页面和 GitHub Pages 静态入口使用同一套应用样式。一次扫描覆盖 46 个入口和分区，另核对了资料库、成绩、会员、设置、学习包、学习会话和 Navi 的内部状态。首次访问的 `#home` 会显示介绍页，有学习记录时才进入今天。

此前独立的 Guided Focus 原型作为视觉基准。Brilliant 的参考价值在于让题目、反馈和下一步按学习顺序出现。Reviewbox 的工作台用左侧可辨识导航、行与分隔线组织信息，手机把主要导航移到底部。学习模式把完整导航让给题目、进度和当前操作。紫色用于行动与选中，绿色用于通过与完成，暖杏用于复核。保留原版 Navi 01 和现有问题、科学绘图及工具流程。

- [Brilliant 互动学习参考](https://brilliant.org/)
- Refero 研究连接返回 `NO_SUBSCRIPTION`。实施参考已认可的本地原型和 Brilliant 官方产品说明。

## Design Tokens

- `--font-display` 用于页面标题、引导标题和重要阶段。简中策略是阿里妈妈方圆体 700，圆角轴 `BEVL` 55。其余使用相应 LINE Seed Bold。
- `--font-body` 用于正文和控件。简中 MiSans Regular，其他主要语言使用相应 LINE Seed Regular。悬浮层沿用应用语言。未覆盖的西文和西里尔字符由系统字库承接。KaTeX 与 MathLive 保持专业字体。
- `--rb-violet` #5a4382、`--rb-green` #257557、`--rb-warn` #94552e 和 `--rb-stroke` #e3dfea。三种主题兼容既有偏好并调整纸色与分隔色。
- 工作台内容边距使用 `--rb-gutter`，手机 17px。44px 为共享控件最小高度，圆角从控件 11px、面板 18px 到弹窗 22px。220px 左右的紧凑空间仍保留原控件和中文换行。
- 瞬时状态约 180ms。应用尊重减少动画偏好。学习中的颜色提示同时配合说明文字。

## 资产与许可证

LINE Seed 和 MiSans 使用官方的原版 Web 字体。按语言和使用字重由浏览器取用，普通访问不会预载其他语言的大字体。Xiaomi 的 Web 字体未做子集、转换或重命名内部字体。署名可在「我的 → 外观设置」查看。

- [阿里妈妈方圆体官方字体页](https://www.iconfont.cn/fonts/detail?cnid=pOvFIr086ADR) · 当前官方声明与旧压缩包中的条款均已核对。官方门户包内 WOFF2、WOFF、TTF 在 Windows Edge 均被拒绝。当前预留已安装原版的字体入口，默认以 MiSans 渲染简体中文标题。新版官方包下载要求先登录 Iconfont，未验收新版包。
- [Xiaomi MiSans 字体许可证与下载](https://hyperos.mi.com/font/en/download/) · 使用官方 WOFF2，随应用嵌入。
- [LINE Seed 官方来源与 SIL OFL 1.1](https://seed.line.me/index_en.html) · EN、JP、KR、TW 使用官方 WOFF2。随文件附官方 OFL 及版权来源。

## 验收边界

浏览器测试使用正式工作台的本地静态入口和独立浏览器环境。新增题目、学习和进度写入走真实页面与 IndexedDB，未通过模拟数据替换任何正式来源。该次浏览器扫描阻止外部请求，因此只能覆盖本地流程和云服务的访客、空态或错误态。记录、构建结果与主要页面对比见交付图集。当前仍有页面和实际业务状态尚未迁移或验证，不能作为全站发布验收结论。

### 结果摘要

- Edge 实际访问 46 个入口与分区，运行时异常 0。抽检 1440px、820px、390px、360px，检查的工作台页面未出现横向溢出。
- 完成正式本地题库表单、Navi 题目上下文、回忆题答案核对、选择题错题解析、学习小结、考试安排新建和回读。
- 通过 `document.fonts` 与浏览器字形记录核验 8 种语言。英、日、韩、繁中加载对应官方 LINE Seed；简中正文与当前标题回退使用 MiSans；西、法和俄文示例中的未覆盖字符使用系统回退。
- 类型检查、资料库、Navi、引导隐私、考试、学习修复及发布回归通过。个人与资料库集成回归为 6/8，失败的两项以旧公开目录请求与旧文案为断言，仍需更新验证覆盖或使用有权限的真实目录联调。
- Vinext 与 Pages 均在独立输出目录构建。Pages 打包包含 19 个 KaTeX WOFF2 资源。原有依赖的大分块和第三方打包告警仍存在。
