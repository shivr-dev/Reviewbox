# 学习计划与证据模型（策略版本 2）

首页继续只有一个学习入口。所有教学、巩固、验证、测试、CE 导入模拟、成绩录入和 GPA 回顾由同一个 Study Director 调度。首次诊断直接消费 dailyStudyPlan 的 recommendation，多科首次定位只保留综合诊断这一份来源。

## 统一策略与目标

lib/policy-config.ts 集中保存题目排序、证据更新、任务效用与信号参数。三个可选择版本保留均衡、保持优先和拓展优先的参数快照。计划的折叠设置支持 Auto / Guided / Manual、切换实验版本与回滚到上次参数；Manual 不影响任何奖励或证据。

目标为 Expected Learning Gain per Minute：把学习机会、信息价值、考试与 GPA 边际影响、长期保持、探索与继续已有任务的价值换成统一效用分量，再乘以完成倾向，除以预计分钟数。当前值是待校准的模型分数，不是真实学习增益的精确预测。

计时中的考试与压力测试是硬约束；普通未完成练习按剩余题量、任务年龄与当前价值比较，可以让位给成绩或其他紧急任务。题卷完整性、争议题暂停、账户、时间预算与强前置依赖不会由效用分数或 AI 绕过。其他候选的高低仅来自相同的效用函数，Action 不再携带任意 priority 整数。

## 可审计推荐

每次呈现推荐保存 study-recommendation：policy snapshot、候选资格、分量贡献、预计分钟、完成倾向、硬约束、选中任务和淘汰原因。选择、暂缓、开始与完成通过 study-recommendation-outcome 关联。记录支持本地持久化、账户隔离和原有私有云同步。开发环境可展开完整 decisionTrace；普通界面只显示解释。

离线评估使用冻结的旧算法与同一份历史前缀，比较排名、推荐变化、latent score 变化、实际后续跨日表现和真实考试结果。参数的完成倾向校准只使用有会话关联的真实完成记录；未到观察期限的任务不会被当作失败。没有实际观测的反事实学习增益和考试收益保留空值。历史回放不能证明新算法带来因果提升，样本不足不会自动改权重。

## 证据与间隔

掌握数值保留为内部 latent score，界面显示未知、学习中、不稳定、已保持、已验证。单次稳定度变化使用有上限的 log-space 平滑，不会一次错误清空多年历史。活动交互用时、页面经过时间与空闲时间分别记录；活动时间是下界估计，纸笔思考可能没有交互，因此时间只作为弱证据，慢作答不降低理解能力。

提示分轻提示、方法提示、关键步骤、接近答案，证据权重不同。提示后的成功可以贡献学习证据，但保持阶段仍需要后续无提示独立检索。错误归因是含 unknown 的分布，只有一次错误不确认概念缺失；高信心基础题错误可先进入小型补救，而不冒称诊断已被证实。

1/3/7 只作冷启动锚点；跨日证据积累后，间隔结合记忆类别、学科、个人历史和稳定度调整。习得阶段允许一个能力连续 4–8 题（默认 6），保持阶段才严格限制重复（默认 2）。只有 requires 权重至少 0.8 的强依赖阻塞后续；helpful 和 parallel 不硬性阻断。

## 教学、测试与负担

同一能力在不同题目连续失分时优先提供已有分步例题、思路和对照，再进入少量巩固；不自动调用 AI。测试的信息价值依据覆盖、不确定性与已有验证连续变化，不存在第七题到第八题的硬跳变。压力测试需有跨日独立基线，并通过信息价值判断是否值得比较限时与平时表现，考前最后一天避免高压模拟。

考试倾斜综合目标差距、范围权重、可改进程度、剩余时间，以及按用户 GPA 公式算出的边际变化。疲劳判断需要错误变化与负担共同支持，单次慢答不算疲劳。完成倾向只是一项保守估计；探索预算默认 20%，不是跳过必要基础或强迫学习新内容的配额。已有足够稳定证据时降低额外验证收益。

题目 difficulty、skill、prerequisite、expectedSeconds 允许附带置信度；多次跨日冲突会产生 metadata suspect 标记，不擅自改题或把题目标注当作绝对真值。单次决策复用 SignalContext 索引，避免逐题重复扫描完整历史。

## 课程闭环修复

每次课程理解检验使用独立 event ID，带 attemptNumber / previousAttemptId；即使两次尝试发生在同一毫秒，也不会被观察层去重掉。已通过状态只属于课程进度，不能覆盖原始作答历史。看到反馈后再答对会保留成功，但不伪装成独立无提示验证。

自由 HTML 的 practice 接口只触发宿主页确认，不能在初始化时自行宣告完课。教学完成后原子建立课程专属练习会话；没有已导入或已有的可用练习时明确提示导入，不消耗 AI 额度。练习完成后原子保存课程完成状态并安排延迟验证，课程修订会使旧版本验证安排失效，最后再交还 Director。

## AI、成绩与兼容

Qwen 仅在重要节点提出可验证 hypothesis，不再选择或重排 action。规则系统独立验证速度、保持、概念或疲劳假设，证据不足不改变计划；有依据的策略影响也有明确上限。AI 永远不能写 mastery、成绩、GPA 或硬约束。保留每天最多一次、滚动七天最多两次和缓存复用。

真实成绩提醒只有在统一调度 primary 为 score 时才自动打开，不再全局抢焦点。未出分可以延后；Manual 不自动弹窗。真实 GPA 与每周学习 GPA 继续区分，公式可修改，游戏奖励不参与成绩计算。schemaVersion 仍为 1，新字段均为可选；旧学习事件保持不可变，所有算法通过重放原始证据计算。
