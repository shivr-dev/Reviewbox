# Review · 自适应复习

个人使用的八科学习工作台。以 Knowledge Node × Skill 的掌握状态安排复习，内容与个人学习记录分开保存。

## 使用

1. 首页选择「准备今日练习」。通过核验的题目逐步进入队列，可以开始复习。
2. 思考后显示答案，选择答错、不确定或答对；主观题输入回答后按评分点批改。
3. 在「资料库」导入自己的内容、建立题目或导出备份。
4. 在「我的」注册或登录学习账户，开启个人云同步。若注册需要邮件确认，确认邮箱后返回此网站登录。
5. 可在学科中心选择知识点、能力、难度及 SAT/ACT 风格，也可建立测试与考试计划。

新空间只有知识框架，没有自动安装的示例题。示例学习包只在手动安装后加入题库。没有公开内容发布或共享入口。

## 实现

- IndexedDB 保存知识、问题、不可变答题事件、考试、笔记、资料、缓存和待同步队列。
- 掌握状态由答题事件重放计算；包含思考时间、快速揭晓置信权重、每日正向增益上限、1/3/7 天间隔验证、遗忘风险、薄弱前置知识与少量稳定知识抽查。
- Supabase Auth + Postgres RLS 负责个人账户和同步。每个同步请求校验预期账户，上传按 UTF-8 大小分批；账户切换不会把未完成任务写入另一个账户。
- Cloudflare Workers AI 使用 `@cf/qwen/qwen3-30b-a3b-fp8`。数学题经过三个隔离解题请求和裁判检查；选择题逐项检查选项；失败内容不进入可用队列。生成中断可继续。
- SVG 按结构化数据绘制数学与物理示意图；函数图像使用受限算术解析器，禁止执行表达式中的代码。
- PDF 文本、DOCX、PPTX、图片 OCR、文本、JSON、CSV、Excel、ZIP 学习包导入。导入结果先供用户确认。学习包格式带 `schemaVersion: 1`。
- 网站入口通过 Sites 的账户访问控制保持仅所有者可访问；Supabase 学习账户用于跨设备同步。

## 配置与开发

运行环境为 Node.js 22.13+，使用已提交的依赖锁文件。`npm ci` 后运行 `npm run dev -- --host localhost`。

服务器运行变量见 `env.example`。实际值由 Sites secret/environment 管理。不要将令牌写入源码、浏览器存储、`NEXT_PUBLIC_*` 或学习包。开发临时变量文件必须忽略并在调试后删除。Supabase 会话采用 AES-GCM 加密的 HttpOnly cookie。

数据库核心表 `public.review_records` 以 `(user_id,id)` 为主键，RLS 限制为 `auth.uid() = user_id`。`review_merge_records(jsonb)` 使用 SECURITY INVOKER，用户身份从当前认证会话推导；答题事件不会被后续内容更新覆盖。内容中心暂时仅保留个人学习包，公共目录访问已关闭。

## 验证

- `npx tsc --noEmit`
- `node scripts/test.mjs`：覆盖算法、隔离、导入、同步、缓存与图形计算测试。
- `npm run build`
- 实际服务调用验证过数学生成、三个独立解答、错误答案拦截、CE 选项检查和主观题评分。
- 临时测试账户验证过密码登录、加密会话、私有记录上传下载、账户不匹配拒绝和退出；测试账户及数据已清除。
- 桌面与移动端通过独立浏览器环境检查；WebMCP 宿主调用仍未单独验证。WebMCP 仅在支持 `document.modelContext` 的环境中注册工具。

## 当前边界

这是个人复习系统的第一版。AI 核验降低出错概率，仍不等同于人工审定课程。起步知识框架覆盖八科主要主题，完整校本教材需通过自己的资料逐步补充。复杂证明、精细仪器读数和高级几何约束尚需扩充专用图形规范。

原始资料以解析文本与知识关联形式保存；当前不保管上传文件的原始二进制附件。扫描 PDF 需先 OCR 或转为图片；旧 PPT 需转为 PPTX。首次图片 OCR 需下载识别资源。单文件 15 MB；单条云记录约 1.9 MB，较长资料需拆分。已有缓存与本地记录可离线复习，新题生成、AI 批改和云同步需要网络。

## 本次更新

- SAT Reading and Writing 为两个 27 题、32 分钟模块；ACT 为 English 50 题、35 分钟及 Reading 36 题、40 分钟，可选 Writing 40 分钟，写作前休息 5 分钟。仅显示英语专项表现，不换算官方量表总分。已保存试卷可反复作答，新题生成默认关闭。
- 拼音题保留手动检查；普通测试交卷后才显示答案并自评，未完成检查可从测试历史继续。选择、填空和连线支持客观评分，数学公式统一渲染。
- 生物作为第八学科，以增量方式添加知识框架；历史知识、作答和个人内容不改写。
- 课程复习从校对后的照片识别文本、文档或输入内容生成结构化课件，由可信 React 组件渲染为互动 HTML 页面。原文按节完整保留，包含例题展开、对比表、过程探索和理解检验；模型内容永不作为脚本执行。
- 课程、章节、历史版本及答疑消息分别保存，沿用私有同步；同一来源自动复用，修订前保留预览和撤销，旧版练习不进入新的计划。
- 课程理解检验关联知识点与能力，已提交的证据保持不可变；反复查看或修改同一道题不会重复提升掌握度。
- 课程答疑可引用选中文字，生成解释或当前小节的修改预览；答疑内容可保存到笔记。照片中的图形、手写内容与复杂公式需在生成前校对和补充。

### 自由互动课件与数据清理

新课程由模型独立设计 HTML/CSS/JavaScript 演示，不再依赖固定讲解卡片。课件在仅允许脚本的独立来源 iframe 内运行；网络、外部资源和父页面数据访问受限。`ReviewCourse` 接口支持读取检验与进度、提交答案、保存互动状态、请求答疑和进入练习。宿主验证来源窗口与每次课件实例的通道，只有本版本所需检验全部通过后才允许完成学习。旧结构化课件仍可读取，并可通过修改预览转换。

中文使用随网站发布的 Noto Sans SC 字体，许可在 `public/fonts/noto-sc/OFL.txt`。字体也由宿主提供给独立课件，无需外部字体服务。

「我的」底部的数据清理需要输入确认文字；不会自动执行。已登录时清理当前学习账户的本地与云端记录，并清理此设备访客空间；其他账户保留。`review_sync_states` 记录重置版本；`review_merge_records_v2` 与 `review_reset_data` 在同一用户状态行上加锁，拒绝旧版本上传并保证清理重试幂等。数据库迁移 `learning_data_reset_generation` 已记录在 Supabase 迁移历史中。未登录时仅清理访客空间。账号与基础学科框架保留。
